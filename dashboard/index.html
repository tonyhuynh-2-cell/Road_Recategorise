Note

Blank-slate re-binning: each road takes the HIGHEST category it earns from data — Nationally Significant (PBS Level 2B access S-06 + ≥2 national criteria: NLTN S-01, metro/urban centres S-02·S-03, port / airport / intermodal S-04·S-05), else State (PBS Level 1 access + ≥2 optional), else Regional (19m B-double access + ≥2 optional), else Local. Dashed roads are provisional — a gate passed with 1 of 2 optional criteria; traffic data could confirm them. The current administrative class is never an input. Verdicts are earned from the data, not forced.
